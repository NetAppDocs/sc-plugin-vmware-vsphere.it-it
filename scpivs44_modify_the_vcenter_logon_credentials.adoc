= Aggiorna le credenziali vCenter configurate in SCV
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Utilizzare questa attività per aggiornare le credenziali di accesso vCenter configurate nel SnapCenter Plug-in per VMware vSphere. SCV utilizza queste credenziali per accedere a vCenter. Quando la credenziale vCenter cambia, aggiornarla in SCV in modo che vCenter rimanga registrato con SCV. Per i backup vVol, annullare la registrazione degli ONTAP tools for VMware vSphere e quindi registrare nuovamente gli ONTAP tools con la nuova password in modo che i backup continuino a funzionare.

.Prima di iniziare
È necessario conoscere l'indirizzo IP e le credenziali di accesso per l'interfaccia utente di gestione SnapCenter Plug-in for VMware vSphere .  È inoltre necessario annotare il token MFA generato dalla console di manutenzione.

* L'indirizzo IP è stato visualizzato al momento della distribuzione del plug-in SnapCenter per VMware vSphere.
* Utilizzare le credenziali di accesso fornite durante la distribuzione del plug-in SnapCenter per VMware vSphere o come successivamente modificato.
* Generare un token MFA a 6 cifre utilizzando le opzioni di configurazione del sistema della console di manutenzione.


.Fasi
. Accedi all'interfaccia utente di gestione SnapCenter Plug-in for VMware vSphere .
+
Utilizzare il formato `\https://<appliance-IP-address>:8080`

. Nel riquadro di spostamento di sinistra, selezionare *Configurazione*.
+
image:scpivs44_image30.png["SnapCenter Plug-in for VMware vSphere"]

. Nella pagina *Configurazione*, nella sezione *vCenter*, seleziona *Modifica*.
. Immettere la nuova password, quindi selezionare *Salva*.
+
Non modificare il numero di porta.
